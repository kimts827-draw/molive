# Moiré 설치 도우미

Moiré에서 만든 디자인을 FileZilla 같은 프로그램 없이 카페24 쇼핑몰에 바로 올려 주는 Windows 데스크톱 앱입니다.
쇼핑몰 웹앱과는 별개의 프로그램이며, 설정과 라이브러리를 따로 씁니다.

## 사용하는 분께

### 먼저 — 디자인 FTP 신청 (처음 한 번)

디자인을 쇼핑몰에 올리려면 카페24에서 **디자인 FTP 권한**을 신청해야 합니다. 1~2분이면 끝납니다.

1. 카페24 쇼핑몰 관리자에 로그인합니다.
2. **디자인(PC/모바일) → 디자인FTP → 디자인FTP 권한신청** 을 차례로 누릅니다.
3. **FTP 접속 비밀번호**를 직접 정하고 **사용 기간**을 고릅니다. (1일 ~ 7일)
4. 신청이 끝나면 화면에 **계정 · FTP 주소 · SFTP 접속포트**가 나옵니다.

비밀번호는 3번에서 직접 정한 그 비밀번호이고, **쇼핑몰 관리자 로그인 비밀번호가 아닙니다.**
사용 기간은 최대 7일이라 기간이 지나면 접속이 막힙니다. 그때는 같은 메뉴에서 다시 신청하고 새로 받은 정보를 쓰면 됩니다.

### 준비물

1. 위에서 신청한 디자인 FTP 정보 (계정 · FTP 주소 · SFTP 접속포트 · 비밀번호)
2. Moiré에서 내려받은 디자인 압축 파일(.zip)

### 설치 순서

1. **1단계 — 접속 정보**: 신청 화면의 FTP 주소 · 접속포트 · 계정을 그대로 옮겨 적고 비밀번호를 넣은 뒤 **접속 확인**을 누릅니다.
   접속이 안 되면 사용 기간이 지났을 수 있습니다. 앱이 오류 문구로 함께 안내합니다.
2. **2단계 — 디자인 고르기**: 목록에서 설치할 디자인을 고릅니다.
   지금 쇼핑몰에서 쓰고 있는 디자인에 설치하면 되돌릴 수 없으니, **카페24 관리자에서 새 디자인을 하나 추가한 뒤 그 디자인**을 고르세요.
   목록의 번호가 어떤 디자인인지 모르겠다면, 카페24 **디자인 보관함**에서 그 디자인의 **미리보기**를 눌러 주소 맨 뒤에 붙은 숫자를 확인하세요. 숫자가 11이면 `skin11`입니다.
3. **3단계 — 파일 고르기**: Moiré에서 내려받은 압축 파일을 고릅니다.
4. **4단계 — 설치**: **설치하기**를 누르고 진행 상태를 봅니다.
5. 끝나면 카페24 관리자에서 그 디자인의 미리보기로 결과를 확인합니다.

### 알아두면 좋은 점

- **접속 정보는 이 컴퓨터에 저장되어 다음에 열 때 그대로 채워집니다.** 다만 접속 상태는 매번 초기화되므로 **접속 확인**을 다시 눌러야 합니다.
- **비밀번호는 저장하기를 켰을 때만 보관합니다.** Windows 로그인 계정으로 잠가서 이 컴퓨터에만 두며, 다른 계정이나 다른 PC에서는 열리지 않습니다. 외부로 보내지 않습니다.
- **파일 고르기는 지난번에 고른 폴더에서 열립니다.** 그 폴더가 없어졌으면 다운로드 폴더에서 시작합니다.
- **고른 디자인 폴더 밖에는 아무것도 쓰지 않습니다.**
- **한 파일이라도 올리지 못하면 설치 완료라고 하지 않습니다.** 어떤 파일이 왜 실패했는지 그대로 보여 줍니다.
- **같은 이름의 파일이 이미 있으면 새 파일로 바뀝니다.**
- 쇼핑몰이 스스로 만들어 관리하는 파일(`sitemap.xml` 등)은 일부러 건드리지 않고 그대로 둡니다.
- 접속하면 디자인 폴더 위치를 자동으로 찾습니다. 못 찾을 때만 1단계 아래 **직접 지정**을 열어 위치를 바꿔 보세요.

## 개발 메모

### 구조

Electron + TypeScript. 번들러 없이 `tsc`만 씁니다.

| 파일 | 역할 |
| --- | --- |
| `src/main.ts` | Electron main. 창·파일 선택·접속 세션. 접속 정보와 원격 작업이 전부 여기서만 일어난다 |
| `src/preload.ts` | `contextBridge`로 화면에 5개 동작만 노출 |
| `src/core/zip.ts` | central directory 기반 ZIP 리더. store·deflate 지원, 암호화·심볼릭 링크 엔트리 거부, CRC 검증 |
| `src/core/remote-path.ts` | 경로 정규화와 스킨 폴더 이탈 차단 |
| `src/core/base-path.ts` | 디자인 폴더 위치를 입력값 → 로그인 위치 → 그 하위 → `/` 순으로 탐색 |
| `src/core/sftp.ts` | `ssh2` 래퍼 (접속 / realpath / readdir / stat / mkdir / 덮어쓰기 writeFile) |
| `src/core/install.ts` | 검증 → 폴더 생성 → 업로드 → 성공·건너뜀·실패 집계 |
| `src/core/settings.ts` | 저장할 입력값의 형태와 검증. 비밀번호 평문은 이 형태에 들어가지 않는다 |
| `src/core/settings-store.ts` | 설정 파일 읽기/쓰기. 암·복호화는 주입받은 코덱에 맡긴다 |
| `src/renderer/*` | 화면 |

화면은 `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`, CSP `default-src 'none'`으로 격리되어 Node·파일시스템·네트워크에 직접 접근하지 못합니다.

### 실행

```bash
npm install
```

```bash
npm start
```

```bash
npm test
```

```bash
npm run dist
```

`npm run dist`는 Windows 실행 파일을 만듭니다. 결과는 `release/`에 두 가지가 나옵니다.

| 파일 | 종류 | 설명 |
| --- | --- | --- |
| `release/Moire-Installer-Setup-0.1.0.exe` | 설치본 (NSIS) | 설치 경로를 고를 수 있고 시작 메뉴에 등록됩니다. 관리자 권한이 필요 없는 사용자 설치입니다. |
| `release/Moire-Installer-0.1.0-portable.exe` | 무설치 | 내려받아 바로 실행합니다. |

두 파일 모두 Node.js나 터미널 없이 실행됩니다. **코드 서명 인증서가 없어 처음 실행할 때 Windows SmartScreen 경고가 뜹니다.** 배포 전에 서명을 붙이는 편이 좋습니다.

```bash
npm run verify:storage
```

`npm run verify:storage`는 실제 Electron 런타임에서 Windows 자격 증명 보호로 비밀번호가 암호화되는지, 저장 파일에 평문이 남지 않는지 확인해 `release/storage-check.json`에 결과를 적습니다.

`npm test`는 카페24 서버 없이 ZIP 파싱·경로 검증과, 인메모리 SFTP 서버(`tests/sftp-server.mjs`)를 띄운 실제 업로드 왕복(폴더 탐색·생성·덮어쓰기·부분 실패 처리·경로 탈출 차단·서버 관리 파일 건너뛰기)까지 확인합니다. 실제 계정에서 확인한 구조(`/` 바로 아래 스킨 폴더)를 재현한 케이스가 들어 있습니다.

### 디자인 폴더 위치

카페24 디자인 FTP 계정은 대개 디자인 루트로 chroot 되어 있어, 접속하면 `/` 바로 아래에 `base`, `mobile`, `web`과 스킨 폴더들이 보입니다. `sde_design` 폴더가 없는 계정이 많아 기본값은 `/`이고, 스킨 폴더가 실제로 보이는 첫 경로를 채택합니다. 못 찾아도 접속은 유지하며 로그인 위치와 확인한 경로, 그곳의 폴더 목록을 진행 기록에 남깁니다.

### 저장되는 값

`%APPDATA%\moire-installer\settings.json` 한 곳에만 저장합니다. 개발 실행(`npm start`)과 배포본이 같은 경로를 씁니다.

| 항목 | 저장 방식 |
| --- | --- |
| FTP 주소 · 포트 · 계정 · 기준 경로 · 마지막 ZIP 폴더 | 평문 JSON |
| 비밀번호 | 저장을 켰을 때만, Electron `safeStorage`(Windows DPAPI)로 암호화한 base64 |
| 접속 성공 여부, 고른 스킨, 설치 결과 | 저장하지 않음 (매 실행마다 초기화) |

암호문은 화면(렌더러)으로 넘기지 않고, 로그에도 비밀번호를 남기지 않습니다. OS 암호화를 쓸 수 없는 환경에서는 비밀번호 저장을 건너뛰고 체크박스를 잠급니다.

### 아직 없는 기능

자동 업데이트, 설치 전 백업·되돌리기, 사용 중인 디자인 자동 판별, 코드 서명.

### 제약

- ZIP은 store/deflate만 읽습니다. 암호로 잠긴 ZIP은 거부합니다.
- 대상 스킨 폴더가 이미 있어야 합니다. 새 디자인은 카페24 관리자에서 만듭니다.
- PC 스킨 폴더에만 설치합니다. `mobile/`, `base/`, `web/`은 건드리지 않습니다.
- 카페24 보호 심볼릭 링크(`order/ec_orderform/**` 등)는 서버 쪽 파일이라 압축 파일에 담기지 않으며 설치 대상도 아닙니다.
