Moiré 설치 도우미

Moiré에서 만든 디자인을 내 카페24 쇼핑몰에 올려 줍니다.

디자인 FTP를 처음 신청하시나요? (신청 방법 보기)

디자인을 쇼핑몰에 올리려면 카페24에서 디자인 FTP 권한을 먼저 신청해야 합니다. 1~2분이면 끝납니다.

  1. 카페24 쇼핑몰 관리자에 로그인합니다.
  2. 디자인(PC/모바일) → 디자인FTP → 디자인FTP 권한신청 을 차례로 누릅니다.
  3. FTP 접속 비밀번호를 직접 정하고 사용 기간을 고릅니다. (1일 ~ 7일)
  4. 신청이 끝나면 화면에 계정, FTP 주소, SFTP 접속포트가 나옵니다. 그 값을 아래 1단계에 그대로 옮겨 적으세요.
  5. 비밀번호는 3번에서 직접 정한 그 비밀번호입니다. 쇼핑몰 관리자 로그인 비밀번호가 아닙니다.

사용 기간은 최대 7일입니다. 기간이 지나면 접속이 안 되니, 같은 메뉴에서 다시 신청하고 새로 받은 정보로 접속하세요.

1단계 쇼핑몰 접속 정보

카페24 쇼핑몰 관리자의 디자인 FTP 권한 신청 정보 화면에 있는 값을 그대로 옮겨 적으세요.

쇼핑몰마다 다릅니다

FTP 주소·포트·계정은 이 컴퓨터에 저장되어 다음에 열 때 그대로 채워집니다. 비밀번호는 위 상자를 켰을 때만 Windows 로그인 계정으로 잠가서 이 컴퓨터에만 보관합니다. 어느 경우에도 외부로 보내지 않습니다.

디자인 폴더를 못 찾을 때 (직접 지정)

접속하면 보통 자동으로 찾습니다. 못 찾았을 때만 여기서 위치를 바꿔 다시 접속 확인을 누르세요.

2단계 어떤 디자인에 설치할까요?

목록의 번호가 어떤 디자인인지 모르겠나요? (skin 번호 확인 방법)
  1. 카페24 쇼핑몰 관리자에서 디자인 보관함을 엽니다.
  2. 설치하려는 디자인의 미리보기를 누릅니다.
  3. 새로 열린 창의 주소 맨 뒤에 붙은 숫자가 그 디자인의 skin 번호입니다.
  4. 숫자가 11이면 위 목록에서 skin11을 고르면 됩니다.
지금 쇼핑몰에서 사용 중인 디자인에 설치하면 되돌릴 수 없습니다.
카페24 관리자에서 새 디자인을 하나 추가한 뒤, 그 디자인을 골라 주세요.
